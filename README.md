# SQ Router Control

Десктопное приложение (Electron) для мониторинга и управления роутингом микшерных
консолей **Allen & Heath SQ** (SQ-5 / SQ-6 / SQ-7) по сети.

Подключается к пульту по TCP (бинарный протокол SQ, порт `51326`), декодирует
текущий инпатчинг и позволяет менять роутинг прямо с компьютера.

## Возможности

- **Подключение к пульту** по IP-адресу или имени хоста; список недавних хостов.
- **Демо-режим** — полная симуляция пульта без реального устройства.
- **Вкладка «Роутинг»**:
  - *Active Patching* — живой инпатчинг с пульта (канал → источник);
  - *Input Patching* — редактируемый список с пресетами **A/B**;
  - **Upload / Download** — перенос списка на пульт и обратно;
  - синхронная прокрутка двух списков;
  - сохранение и загрузка роутингов (локально, до 100 записей);
  - запрос полного дампа роутинга у пульта.
- **Вкладка «Монитор»**: выбор L/R выходов и переключение роутинга выбранного
  канала, микса или Main LR в эти выходы:
  - стерео-пара → левый канал → L-выход, правый канал → R-выход;
  - моно-канал, микс, Main LR → источник в оба выхода L и R;
  - снятие выбора не меняет роутинг — выходы сохраняют последний источник;
  - тумблер «Применять» включает/выключает отправку команд на пульт;
  - горячие клавиши: `←`/`→` — переключение, `1–9`/`0` — миксы 1–10, `Esc` — сброс.
- **Вкладка «Журнал»** — журнал кадров и событий протокола.
- **Определение модели** пульта (SQ-5 / SQ-6 / SQ-7) и адаптация интерфейса
  под её физические входы/выходы.

## Требования

- Node.js 18+ и npm
- macOS / Windows / Linux (сборка под macOS — arm64 и universal)

## Установка и запуск

```bash
npm install        # установка зависимостей
npm start          # сборка (webpack) и запуск приложения
npm run dev        # то же, с логированием Electron
```

Проверка типов:

```bash
npm run typecheck  # tsc --noEmit
```

## Сборка дистрибутивов

```bash
npm run pack       # сборка в папку release/ без установщика
npm run dist       # сборка установщиков (dmg/nsis/AppImage)
```

Для сборки только под Apple Silicon:

```bash
npm run build && npx electron-builder --mac --arm64
```

Готовые сборки появляются в `release/`. Подпись кода отключена
(`identity: null`), поэтому при первом запуске macOS может запросить
подтверждение через «Правый клик → Открыть».

## Использование

1. Запустите приложение.
2. Введите IP-адрес пульта (по умолчанию порт `51326`) и нажмите
   «Подключиться», либо запустите демо-режим.
3. Во вкладке «Роутинг» редактируйте инпатчинг и переносите его на пульт
   кнопками Upload/Download.
4. Во вкладке «Монитор» выберите L/R выходы и кликайте по каналам/миксам,
   чтобы направить их в выбранные выходы.

## Протокол (кратко)

Патчинг на SQ передаётся DSP-кадрами `F7 0B 0B 0D [ch] [modifier] [valLo] [valHi]`:

| modifier | назначение |
|----------|------------|
| `0x01–0x04` | инпатчинг (физический вход → канал микшера) |
| `0x0F` | аутпатчинг (шина/канал → физический выход) |
| `0x11` | мониторный выход (PAFL L/R → выход) |
| `0x16/0x17` | выход FX-возврата (L / R) |

Начальное состояние микшера приходит в дампе ParamData (sub=0x04, ~97 КБ)
сразу после подписки: имена каналов, инпатчинг, фейдеры, мьюты, гейны,
тримы, панорама, HPF, гейт/комп/дилей и сенды. Приложение разбирает его
целиком (карта смещений — [allen-heath-sq-tools](https://github.com/hrueger/allen-heath-sq-tools)),
поэтому состояние каналов известно сразу, не дожидаясь живых изменений;
оно доступно в IPC-снапшоте (`channels`) для будущего UI. Живые DSP-кадры
обновляют то же состояние по ходу работы.

### UDP-метры

Порт метров согласовывается при подключении (`MeterSub`, sub=0x00). Каждая
датаграмма: `[0x7F] [id:u8] [len:u16LE] [00 00] [тело]`, тело — u16 LE;
дБФС = (значение − 0x8000)/256, `0x1201` — «тишина», `> 0x8000` — клип,
`0x0000` и `≥ 0xF000` — данные-заглушки:

| id | тело | содержимое |
|----|------|------------|
| `0x06` | 1056 Б | 48 входов × 11 слотов (уровни + служебные) |
| `0x17` | 96 Б | 48 входов, по одному значению на канал |
| `0x18` | 480 Б | 40 шин × 6 слотов: входы 0–22, **Main LR = 23**, **Mix 1–12 = 24–35**, FX send 1–4 = 36–39 |

В 6-слотном блоке шины две L/R-пары тапов — слоты `[0,1]` и `[3,4]`
(слоты 2 и 5 — заглушки); по стороне берётся максимум. Моно-шина метрирует
L и R бит-в-бит, стерео — различает; на этом основано определение стерео
миксов в UI. Стерео-линки входных каналов читаются из таблицы в ParamData
(офсет 81548, подтверждено на SQ-5 FW 1.6); режим стерео/моно самих миксов
в ней не найден.
