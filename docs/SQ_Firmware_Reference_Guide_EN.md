# Allen & Heath SQ Firmware Reference Guide

**Language:** English\
**Product:** Allen & Heath SQ digital mixing system\
**Primary source:** [SQ Firmware Reference
Guide](https://support.allen-heath.com/hc/en-gb/sections/45946758116241-SQ-Firmware-Reference-Guide)

This Markdown file is an English-language index to the official SQ
Firmware Reference Guide. It preserves the original article names and
links to the manufacturer's current documentation rather than
reproducing the full copyrighted articles. Use the official pages for
complete procedures, parameter lists, illustrations, and
firmware-specific details.

## 1. Operational Overview

**Official article:** [SQ. Operational
Overview](https://support.allen-heath.com/hc/en-gb/articles/45189802074641-SQ-Operational-Overview)

Covers the physical controls, channel types, on-screen parameters and
menus, title bar, Home screen, diagnostics, basic workflow concepts,
SQ-Rack screens, SQ-Control, and the screen reference.

Topics to look up: - Fader layers, channel selection, Mute, PAFL,
Processing and Routing. - Main LR, Mix, FX Send/Return, Matrix, DCA and
MIDI strips. - Pre-Fade and Post-Fade sends. - Copy, Paste and Reset
operations. - SQ-Rack Faders screen and SQ-Control widgets.

## 2. Connections and Patching

**Official article:** [SQ. Connections and
Patching](https://support.allen-heath.com/hc/en-gb/articles/45261631285009-SQ-Connections-and-Patching)

Describes local inputs and outputs, SLink, USB, Network, I/O Port,
footswitch connections, and the I/O patching matrix.

Topics to look up: - Local XLR, TRS, ST3, AES and headphone
connections. - SLink protocols and supported expander configurations. -
USB-B audio/MIDI and SQ-Drive. - Patching input sockets to input
channels or Mix Ext In. - Patching Direct Outs, Mix Outs, Rack FX and
Listen Out to output sockets.

## 3. Processing

**Official article:** [SQ.

Topics to look up: - Preamp and external input settings. - HPF, Gate,
Insert, PEQ, GEQ and Compressor. - FX processing and channel-specific
processing options. - Processing libraries and copy/paste/reset
behaviour.

## 12. Mix/System Reset

**Official article:** [SQ. Mix/System
Reset](https://support.allen-heath.com/hc/en-gb/articles/45947235418385-SQ-Mix-System-Reset)
