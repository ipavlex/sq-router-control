# Проверка режима моно/стерео миксов и матриц (ParamData) — ВЫПОЛНЕНО

> Результат серии контролируемых дамп-экспериментов на SQ-5 fw 1.6
> (2026-10-15, хост 192.168.31.10). Все эксперименты §3 старой редакции
> выполнены; модель кодирования подтверждена и перенесена в
> [`SQ-PROTOCOL.md`](SQ-PROTOCOL.md) §8.5 и декодеры `stereo-links.ts`.
> Раздел 2 оставлен как инструмент для будущих проверок.

## 1. Итоговая модель

| Объект | Где закодировано | Статус |
|---|---|---|
| Состав шин (N aux + M group) | шапка `@61` = group, `@65` = aux | подтверждено на двух конфигурациях (10+2 и 5+7) |
| Стерео миксов (Mix 1–12) | шапка `@90..91` u16LE, bit i = Mix i+1 стерео | подтверждено переключением Mix 1 (`0xFFE0 ↔ 0xFFE1`) |
| Стерео матриц | шапка `@93`, bit 3/4/5 = спарена пара 1/2/3 (`0x73+0x76`, `0x74+0x77`, `0x75+0x78`) | подтверждено переключениями всех трёх пар (`0x38→0x30→0x20→0x00→0x08`) |
| Устройство матриц | 6 моно-шин `0x73–0x78`; стерео = 2 шины (L+R), разбиение освобождает R-шину как новую моно-матрицу | подтверждено наблюдением меню (3 стерео → 4 → 6 записей) |

**Опровергнуто** (ранние гипотезы):

- байт `+331` блока канала — **не** стерео-режим миксов. Это «липкий»
  послотовый флаг: переживает смену Bus Config без обновления (10 активных
  aux, `1` только на 5 слотах) и не меняется при переключении стерео.
  Снимки «5 пар»/«4 пары» из старой редакции — просто число aux.
- encoding-A пары в link-регионе — **не** надёжный маркер стерео: `0x10`-записи
  исчезают при разбиении матрицы, но не возвращаются при обратном спаривании
  и теряются при пересоздании шин (у стерео-Mtx1 в busE пары не было).
- `+328` — не надёжный маркер типа шины (у активного aux 7 «Bass» — `0x00`).

## 2. Инструменты (для будущих проверок)

- **CLI-тула `sq-dump`** — приложение для дампа не нужно:
  ```bash
  npm run sq-dump -- capture 192.168.1.30 --label baseline   # дамп + отчёт
  # …меняем ОДНУ настройку на пульте…
  npm run sq-dump -- capture 192.168.1.30 --label experiment
  npm run sq-dump -- diff pd-dumps/pd-*-baseline.bin pd-dumps/pd-*-experiment.bin
  ```
  `capture` печатает дайджест: состав шин (`@61/@65`), битмаску стерео миксов
  (`@90..91`), спаренные матрицы (`@93`) и липкие A-метки. `diff` расшифровывает
  каждый байт (шапка, блок канала, fader-секция, link-таблица, регион линков
  шин) с вердиктами. Дампы пишутся в `pd-dumps/` (git-ignored) с меткой
  времени и `--label`. `info <bin>` — полный отчёт диагностики.
- Ограничение основного приложения (оставлено как есть): дамп пишется **один**
  раз за соединение; для нового дампа — переподключение. Туле это не важно.
- macOS-пути дампов приложения (если используется оно):
  `~/Library/Application Support/sq-router-control/diagnostics/`.

## 3. Журнал экспериментов (дампы в `pd-dumps/`)

| Дамп | Состояние пульта | Ключевой результат |
|---|---|---|
| `connect-test` | исходный show | baseline |
| `baseA` | 10 aux + 2 group | шапка `@61=02 @65=0a`, маска `0xFC00` |
| `busB` | Bus Config → 5 aux + 7 group | `@61=07 @65=05`, маска `0xFFE0`; разбор aux стирает имя, `+17/+20`, `+331→0`, сенды |
| `busC` | без изменений конфига | `busB` + 2 байта шума — подтверждение чистоты |
| `busD` | Mix 1 → стерео | **`@90: 0xe0→0xe1`** — найдена битмаска стерео миксов |
| `busE` | конфиг возвращён к 10+2, много правок | шапка подтверждена на новом конфиге; `+331` «липкий» (10 aux, флаг на 5); A-пара 0x73 потеряна при стерео |
| `busF` | Matrix 1 → моно | **`@93: 0x38→0x30`** — найдена битмаска матриц (bit3 = Mtx1) |
| `busG` | Matrix 2 → моно | `@93: 0x30→0x20` (bit4 = Mtx2) |
| `busH` | без изменений | идентичен `busG` |
| `busI` | Matrix 3 → моно | `@93: 0x20→0x00` (bit5 = Mtx3); меню показывает 6 матриц |
| `busJ` | Matrix 1 → снова стерео | `@93: 0x00→0x08` — обратимость; A-пары не вернулись |

## 4. Как читать diff

- Шапка: `@61/@65` — состав, `@90..91` — стерео миксов, `@93` — матрицы.
- Блок канала: `884 + b3·336`; `+331` — липкий флаг (НЕ стерео), `+332` —
  флаги (bit0 полярность, bit1 mute).
- Стерео-линки входов — таблица `81548` (encoding A/B, см. `stereo-links.ts`).
- Если менялась одна настройка, «шум» diff минимален; посторонние изменения —
  от живого сигнала/фейдеров.
