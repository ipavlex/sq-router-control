# Вкладка «Метры»

> Обзорная вкладка метро-индикации всех каналов пульта: под основным меню —
> блок под-вкладок **Inputs / Mix / FX / USB**, под ним — сетка ячеек.
> Каждая ячейка показывает: 1) уровень сигнала **только графически** (без
> чисел), 2) индикатор гейта, 3) индикатор компрессора, 4) индикатор mute.
> Всё read-only: клики по ячейкам ничего не делают.

## 1. Каркас вкладки

- Кнопка `📊 Метры` в топбаре (рядом с «Монитор»), переключение через
  `showView("meters")` (`src/renderer/core/utils.ts`).
- Фрагмент разметки `src/renderer/tabs/meters/view.html`, зарегистрирован
  в `webpack.config.js` (`HtmlFromTabsPlugin.fragments`, плейсхолдер
  `<!-- @tab:meters -->` в `dashboard/view.html`).
- Логика `src/renderer/tabs/meters/index.ts`; DOM-ссылки `metersSubtabs` /
  `metersGrid` — в `ElementRefs` (`core/types.ts`,
  `core/utils.ts`).
- Стили — секция «Meters tab» в `src/renderer/assets/styles.css`, только
  токены `:root`. Бары переиспользуют класс `.ch-meter` (scoped-вариант
  внутри `.m-cell` — статический, не абсолютный, как у кнопок монитора).

## 2. Под-вкладки и источники данных

| Под-вкладка | Ячейки | Уровень | Гейт / Комп | Mute |
|---|---|---|---|---|
| **Inputs** | все 48 входов; стерео-пары (`state.stereoPairs`) объединены в одну ячейку с двумя барами L/R и номером пары («3-4») | UDP `0x06`/`0x17` (`m.inputs`/`m.clip`) | вкл/выкл из `channelStates.gateOn/compOn` | `channelStates.muted` |
| **Mix** | секции **Aux / Group**, ниже одна строка с подписями: **Master** (Main LR) слева, правее с небольшим отступом **Mtx** — слоты `0x73–0x78` (pair-aware, `matrixButtonSpecs`); Aux — первые `auxCount` слотов микс-пула (`0x58+`, состав из снапшота `@61/@65`), Group — шины `0x48+` (`groupCount`) | UDP `0x18`: Aux и Master — живые метры; Group и Mtx — каркас (в декодированных пакетах их нет) | n/a (на шинах гейта/компа нет) | из `channelStates` |
| **FX** | FX send 1–4 (шины `0x18` 36–39) + FX return 1–4 (`0x40–0x43`) | send — `m.fxSends` (декодер `meters.ts`); return — каркас (уровни не декодированы) | n/a | только у return |
| **USB** | — (заглушка «нет данных») | формат метро-пакетов не декодирован | — | — |

Формат ячеек един для всех под-вкладок (channel-strip): узкий бар 8px в
контейнере `.m-bars` (стерео — соседние L/R), высокое тело ячейки 110px,
заголовок в две строки — номер канала (`m-cell-num`, у стерео-пар «3-4»)
над именем. Имена каналов — из последнего
снапшота (`snapshot.inputs` для инпутов, `mixNames`/`groupNames`/`fxNames`);
незапатченные входы подписываются `Ch N`. Стерео-миксы и Main LR показывают
два бара (L | R) из `mixesL/mixesR` и `mainLRL/mainLRR`; стерео-режим — из
`mixStereoPairs` (битмаска `@90..91`, см. `SQ-PROTOCOL.md` §8.5).

## 3. Индикаторы G / C / M

- **G (гейт)** и **C (компрессор)** — на входных каналах: горят, когда
  процессор включён (`gateOn`/`compOn`). На шинах/FX — приглушённые «n/a».
- **M (mute)** — горит красным при `muted = true`.
- **Срабатывание (динамика)** гейта/компрессора и класс `.act` (янтарный)
  зарезервированы: соответствующие значения в метро-потоке не декодированы —
  нужен реверс на живом пульте (см. `BACKLOG-NO-CONSOLE.md`, группа B).
  Подсказка у флага честно об этом говорит.

## 4. Поток обновлений

Существующий канал `sq:meters` (UDP ~25–50 пакетов/с) → `meters.updateMeters` →
коалесция `pendingMeters` + `requestAnimationFrame` (общий паттерн с вкладками
«Роутинг»/«Монитор») → `applyMeters`: высота бара через `dbToPercent`, цвет
через `meterClassName` (`src/renderer/core/meters.ts`), клип — класс `.on` у
`.ch-meter-clip`. Флаги G/C/M читаются из `state.channelStates` при каждом
проходе и обновляются вместе со снапшотом (`onRoutingSnapshot` → rebuild).

Сброс: `meters.reset()` при входе в дашборд, `meters.clearMeters()` при
отключении/реконнекте (как у остальных вкладок).

## 5. Демо-режим

`DemoMetersSim` (`src/main/demo-meters.ts`) синтезирует и FX send 1–4
(контрибьюторы + trim, как у миксов). `seedMixerState` (`demo.ts`) ставит
гейт на каждый 5-й канал и компрессор на каждый 3-й — флаги G/C видны в
демо в обоих состояниях. Mute уже вращается живым тумблером демо-сценария.

## 6. Ограничения (группа B — нужен пульт)

- **Динамика гейта/компрессора** не декодирована (кандидаты — слоты 8–10
  пакета `0x06`, пакет `0x07`); индикаторы показывают только вкл/выкл.
- **FX return**: уровней в декодированных пакетах нет.
- **Группы 1–4**: в `0x18` их нет — бар-каркас без уровня.
- **USB-метры**: формат не декодирован (`0x07`/`0x09` — кандидаты).
- Привязка шин 36–39 к FX send 1–4 подтверждена раскладкой `0x18`
  (`SQ-PROTOCOL.md` §8.4), но живая проверка баров — на пульте (MON-B2).
