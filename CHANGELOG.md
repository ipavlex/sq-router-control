# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3.0] — 2026-08-20

### Добавлено
- Живые уровни сигнала (метры) в таблице ACTIVE PATCHING: горизонтальный бар
  (зелёный → янтарный → красный), значение в дБ и красная точка перегруза (clip).
  Данные декодируются из UDP-потока метров, который пульт шлёт после хендшейка.
- Пакеты декодируются в main-процессе (`src/main/meters.ts`): id=0x06 (48×11
  слотов) и id=0x17 (по одному уровню на вход); уровень = (значение − 0x8000)/256
  дБ, 0x1201 — «нет сигнала», клип — выше 0 дБFS. Значения проверены на реальном
  захвате трафика пульта.

### Изменено
- UDP-слушатель в `connection.ts` теперь декодирует метро-пакеты и эмитит
  событие `meters`; main-процесс пробрасывает их рендереру через IPC, рендерер
  объединяет поток (~25–50 пакетов/с) в один кадр обновления.

## [1.2.1] — 2026-08-20

### Изменено

## [1.2.0] — 2026-08-20

### Добавлено
- Чекбокс выбора каналов у каждой строки INPUT PATCHING; отмечается вручную
  или автоматически при изменении параметров строки.
- Чекбокс «выбрать все» в заголовке колонки.
- Upload отправляет на пульт только отмеченные каналы.

### Изменено
- Выделение хранится в наборах A/B и сохраняется при переключении списков
  и после отправки на пульт; обновления Active Patching на него не влияют.
- При загрузке сохранённого роутинга строки, отличающиеся от роутинга пульта,
  отмечаются автоматически.

## [1.1.0] — 2026-08-20

### Добавлено
- Кнопка A/B Swap в колонке переноса: одним нажатием меняет роутинг на пульте.
  Целевой список определяется по-последнему загруженному на пульт; если ни один
  список ещё не загружался, применяется активный. Кнопка активна только когда
  списки A и B различаются.
- Вспышка заголовка "Active Patching" при смене роутинга окрашивается в цвет
  применённого списка (синий — список A, зелёный — список B).

### Изменено
- Списки A и B заполняются роутингом пульта сразу при подключении, а не
  «лениво» при первом переключении. Неиспользованный соседний слот намертво не
  блокируется пустой запечатанной копией — данные подтягиваются по завершении
  начальной загрузки.
- При загрузке сохранённого роутинга в один список соседний (если ещё пуст)
  заполняется роутингом пульта, чтобы кнопка свапа сразу стала доступной.
- Отправка патчей на пульт вынесена в единый `sendPatchesToConsole`, общий для
  Upload и Swap.

## [1.0.1] — 2026-08-19

### Изменено
- Рендерер разбит на модули по вкладкам (`utils.js`, `connect.js`, `routing.js`,
  `monitor.js`, `log.js`, `renderer.js`) — без изменения поведения.
- Вкладка «Монитор»: выбор канала, микса или Main LR теперь меняет **роутинг**
  источника в выбранные L/R выходы вместо PAFL (соло):
  - стерео-пара → левый канал → L-выход, правый канал → R-выход;
  - моно-канал, микс, Main LR → источник в оба выхода L и R;
  - снятие выбора не меняет роутинг — выходы сохраняют последний источник;
  - смена L/R селекторов перенаправляет активный источник;
  - включение «Применять» сразу применяет текущий выбор.
- Добавлен мост `sq.setOutputPatch` (output-patch кадр `0x0f`) в main-процесс.

## [1.0.0] — 2026-08-19

### Добавлено
- Подключение к пульту Allen & Heath SQ по TCP (порт 51326, бинарный протокол).
- Демо-режим без пульта с симуляцией роутинга.
- Вкладка «Роутинг»: Active Patching, редактируемый Input Patching (списки A/B),
  Upload/Download, синхронная прокрутка, сохранение/загрузка роутингов.
- Вкладка «Монитор»: выбор L/R выходов, соло каналов, миксов и Main LR (PAFL).
- Вкладка «Журнал»: журнал кадров и событий.
- Определение модели пульта (SQ-5 / SQ-6 / SQ-7) и адаптация под её I/O.
- Сборка под macOS (arm64 / universal).
